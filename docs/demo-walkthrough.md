# Demo Walkthrough Script

Use this outline for a short silent or narrated portfolio video.

## Suggested Length

60 to 90 seconds.

## Flow

1. Open the SolPro public portal.
2. Show premium property browsing.
3. Open one property detail page.
4. Submit a buyer lead.
5. Switch to the agent dashboard.
6. Show lead intake and lead score/context.
7. Open property or lead management.
8. Show admin/agency workflow if available.
9. Close with the GitHub public case study and CV project title.

## Text Overlays

- Private real estate SaaS platform
- Public portal + agent dashboard
- Multi-agency architecture
- Lead capture and CRM workflow
- Tenant-aware backend design
- AI-assisted property analysis concept
- Production readiness documentation

## Recording Tips

- Use browser zoom around 110% or 125%.
- Hide secrets, local tokens, and private data.
- Keep the cursor movement slow.
- Prefer a clean 1080p screen recording.
- Do not expose the private repository code in the video.
